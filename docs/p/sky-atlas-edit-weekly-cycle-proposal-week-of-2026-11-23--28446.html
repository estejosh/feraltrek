Atlas Edit Weekly Cycle Proposal - Week Of 2026-11-23

Core GovOps submits this week's Atlas edits for Sky: NFAT pilot definitions, a Swap Asset Facet, higher Osero rate limits and housekeeping fixes. Discussion stage.

Posted by Core GovOps on the Sky forum, this is the weekly batch of edits to the Atlas governance documents. The post lists eleven edits. It adds definitions for NFATs and NFAT Facilities and a five-phase NFAT Pilot with a Test NFAT Facility. It adds the Swap Asset Facet and its Controller functions to the Diamond PAU documents, ahead of approval on the Beacon in a future Executive Vote. It adds the Spark Diamond PAU to the Ethereum Mainnet PAS, to be configured in a future Executive Vote. It allows Distribution Reward, Integration Boost and Pioneer Rewards payments to be made from the Demand Side Buffer or within the Monthly Settlement Cycle, and names the Sky Surplus Buffer as the source of monthly buffer transfers and Demand Side Buffer top-ups. It allows a smart contract, or the Multisig holding the Curator role, to hold the Allocator role on Morpho vaults. It records 15,000,000 USDC and 10,000,000 USDC per day as the highest ERC-4626 Facet deposit rate limit operated in production. For Osero, it adds the Test NFAT Facility as an Allocation System Primitive Instance with subscribe rate limits per pilot phase, raises the Gauntlet Instance deposit rate limits to 50,000,000 USDC and 50,000,000 USDC per day and the CCTP rate limits to 25,000,000 USDC, and adds reward code 3017 (Yearn Finance) to the Distribution Reward Instances. Housekeeping updates correct co-curator addresses on an X Layer Morpho USDC vault, update factory addresses, remove the PAU Assembler, add a Morpho Vault Change Note Template location, point Osero rate limit values to each Instance Configuration Document and update completed implementation language. The full text is in a linked pull request. Open questions: the post gives no vote date, and several items depend on later Executive Votes.
