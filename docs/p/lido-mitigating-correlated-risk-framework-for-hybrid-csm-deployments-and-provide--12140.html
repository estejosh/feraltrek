Mitigating Correlated Risk: Framework for Hybrid CSM Deployments and Provider Diversity Scoring

A Lido research post proposes a blueprint for Community Staking Module operators to run hybrid home and cloud setups, plus a provider diversity score, to cut correlated outage and slashing risk.

Many permissionless CSM operators rely on the same hosted providers. A single provider outage could take a large group of Lido validators offline or cause correlated penalties. The post proposes two things. First, a standard hybrid blueprint: a low-power home client pair as hot standby, with open-source failover scripts that move validator keys without double-signing. Second, a provider diversity framework to score and steer operators away from concentration. It is research-stage. No budget, owner or timeline is set in the opening post.
