PSM-USDC-A housekeeping

A technical post proposes fully offboarding the inactive legacy PSM-USDC-A vault type in Sky, removing its registry entries and permissions, with a core spell planned for 2026-11-19.

Sidestream prepared this housekeeping item for the legacy PSM-USDC-A ilk, following earlier PSM-GUSD-A and PSM-PAX-A cleanups. The post says the ilk has been inactive for a long time with no plans to re-enable it: it was migrated to LITE-PSM-USDC-A, its debt ceiling was set to 0 and it was removed from AutoLine in the 2024-10-04 spell, and the global debt ceiling was reduced to match. Its liquidation contract is stopped and has never run an auction. The proposed actions remove the ilk from ILK_REGISTRY and LINE_MOM, revoke its permissions on MCD_VAT and MCD_DOG, and remove its contracts from the chainlog. The join contract still holds 99.328577 USDC, described as a donation that is recoverable, and 47,209.819413 DAI sent by mistake in 2023, described as not recoverable because the contract has no way to move it. A Core Facilitator must confirm that the USDC can be exited to the CORE_COUNCIL_BUDGET_MULTISIG. The pause proxy keeps its permissions on the offboarded contracts, which the post says deviates from the PSM Offboarding Checklist but adds no security benefit if removed. No audit is listed because this is housekeeping. No new contracts were deployed.
