Upgrade the v4 Protocol Fee Adapter

A Uniswap Snapshot vote on replacing the v4 fee policy with a flexible per-hook ruleset system on all eight chains, with current fee levels unchanged.

This Snapshot is the vote stage of the proposal discussed in the forum temp check. It uses the expedited process: a five-day Snapshot followed by an onchain vote. It replaces the V4FeePolicy of the V4FeeAdapter on all eight chains where v4 protocol fees are live. Fee levels stay unchanged for every pool currently paying the fee. Pools using Uniswap Labs-owned hooks are opted in; fees are not enabled on third-party hooks. The adapter resolves a pool fee in order: pool override, hookless ruleset, governance-assigned ruleset, hooked static-fee ruleset, hook opt-in through getProtocolFee, then a global default set to 0. If a ruleset or hook reverts, the pool keeps its current fee. A parallel Snapshot would activate v4 fees under the same framework on five more chains.
