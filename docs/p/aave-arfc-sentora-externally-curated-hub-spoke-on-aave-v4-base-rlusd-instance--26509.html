[ARFC] Sentora Externally Curated Hub & Spoke on Aave V4: Base RLUSD Instance

An ARFC proposes a second Sentora-curated Aave V4 Hub on Base where RLUSD is the only borrowable asset, with cbBTC and cbXRP as launch collateral.

This ARFC would deploy a second Sentora Hub and Spoke instance on Aave V4, on Base, under the existing Sentora framework. One isolated Hub makes RLUSD the sole borrowable asset, served by two Spokes: Bluechip (cbBTC and cbXRP collateral) and Yield (USDe, sUSDe, syrupUSDC, pre-approved with zero caps until each is live on Base with a qualifying oracle). Launch caps include RLUSD 30M add / 27M draw on Bluechip and 40M / 36M on Yield. Collateral factors range from 77% (cbXRP) to 91.5% (USDe). The RLUSD curve runs from a 0.50% base rate with 90% optimal usage and a 20% liquidity fee. Revenue is split 50% Aave DAO, 50% Sentora. The Aave DAO keeps admin ownership through the Governance Short Executor; Sentora operates through revocable roles. Risk-increasing changes wait 48 hours, and the DAO can cancel them. Sentora would publish monthly reports. Stated next steps are community feedback, a Snapshot vote if a service provider objects or a first instance on a new network requires it, then an AIP. Open questions: provider objections and oracle readiness for pending assets.

Flags: new Hub on Base with RLUSD as sole borrowable asset, 50% revenue share to Sentora, pre-approved collateral activates later via timelock
