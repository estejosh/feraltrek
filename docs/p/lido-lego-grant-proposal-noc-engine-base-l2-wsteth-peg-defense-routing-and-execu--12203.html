LEGO Grant Proposal: NOC Engine, Base L2 wstETH Peg-Defense Routing and Execution Telemetry

A team asks for a $10,000 LEGO Pebble Grant to build a wstETH peg-defense routing adapter on Base and a public telemetry dashboard.

NOC Labs applies for a LEGO Pebble Grant worth $10,000 equivalent, payable in LDO, DAI or USDC, targeting wstETH on Base mainnet. The post argues that wstETH liquidity on Base is split across several pools, that large trades face wider spreads in stressed markets, and that Lido lacks a dedicated Base execution telemetry suite. The team says it has already self-funded a Rust execution engine, a Base settlement contract with 56 invariant tests passing, and distribution through an aggregator. Phase 1, $5,000, is a wstETH flash-liquidity adapter using a zero-fee flashloan source for atomic rebalancing on Base. Phase 2, $5,000, is a public Dune dashboard and an empirical research report on wstETH market depth and slippage on Base. Claims about latency, spreads and test results come from the applicant and are not independently verified in the post. Open questions include how milestones are verified and whether the deliverables are open source.
