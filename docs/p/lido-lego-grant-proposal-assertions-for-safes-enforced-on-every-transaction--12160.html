LEGO Grant Proposal: Assertions for Safes, Enforced on Every Transaction

Asks Lido's LEGO to put $10,000 toward a $75,000 Blossom Labs project that adds transaction-checking rules (assertions) directly to Safe multisigs.

One of four sub-proposals under the TheDAO Security Fund request to LEGO. Blossom Labs would build 'Protections': assertions installed on a Safe so every transaction must pass set rules or revert, regardless of who wrote it. The post says a transaction that swaps the Safe's code, as in the Bybit incident, would always revert, owners could add custom rules, and signers could read each rule in plain language before signing. The author says assertions were used manually when TheDAO Security Fund migrated $220M, and this grant aims to make that a few clicks. Of the $75,000 goal, $26,000 pays only when at least 10 outside Safes governing $10M+ combined run assertion-checked mainnet transactions, and $3,000 requires non-grant revenue. Lido's share is $10,000 (13% of the goal), sent to the initiative Safe 0x9894...0d28 on Ethereum mainnet in USDC, USDT, DAI or USDS, or pledged and sent only if the full goal is raised by February 1, 2027. The post says Lido's LEGO and Treasury Safes could enable it with one transaction.
