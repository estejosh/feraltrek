# Graveyard

Ideas and channels that were tried and failed. Do not retry these.

- Selling Haiku-powered APIs (transaction classifier, governance, contract risk) by cold outreach to DAOs:
  no auth, no billing, needed a human to sell. Replaced by the self-serve digest. (2026-10)
- Transaction classifier pricing ($300/month for 100M tx): cost about 100x the price. Do not revive at that price.
- Nostr-only posting (6 notes/day, no hashtags, no landing page for searchers) as the main channel: 11 days, zero measurable engagement or payments. Kept as a side channel only. (2026-11)
- Selling on a storefront that does not say what paid adds over free: do not leave paid-vs-free unclear. (2026-11)
- Changing GitHub (repo topics, settings) as a discovery channel: RULES.md makes GitHub a read-only relay copy; not allowed. (2026-11)
- Governance Digest as the main product (11-23): 3 distribution experiments in 4 weeks, 164 items, 0 visitors measured, 0 payments, 0 subscribers. Free site already contains the full analysis and /closing-soon/ is usually empty, so paid adds little. Kept only in maintenance mode. Do not add new features to it.
- Single-channel SEO bets with no way to measure indexing (11-23): never repeat a channel without instrumentation (an indexed-page check or a visible counter) from day one.
